# 字幕分割仕様 — v1.0.5

## 目的と適用範囲

長い動画でも発話の区切りと時刻を字幕に反映し、手動で区切り・表示時刻を修正する負担を減らす。SRT / VTT に同じ分割・時刻生成処理を適用する。固定文字数による強制分割と文字数比例の時刻配分は行わない。認識結果の要約・言い換え・補完・フィラー除去は行わない。

Electron → Python CLI の構成、CLI引数、認識モデルの選択、CPU / int8 設定、SRT / VTT / TXT の形式を維持する。新しいUI・外部API・LLM校正は追加しない。

## 原文と単語時刻の対応

`model.transcribe()` に `word_timestamps=True` を渡す。[faster-whisper の単語時刻仕様](https://github.com/SYSTRAN/faster-whisper#word-level-timestamps)に従い、`segment.words` の `word` / `start` / `end` を使用する。

1. `segment.text` の空白以外の文字について元の文字位置を保持する。
2. 各 `word.word` の空白以外の文字列を先頭から順に照合する。句読点・全角半角・大文字小文字は変更しない。繰り返し現れる語も順に対応付ける。
3. segment全体を過不足なく覆うこと、時刻が有効で語順に並んでいることを確認する。
4. 実際の分割には原文の連続した部分文字列を使う。分割した原文を連結すると元の本文と一致する。空白・句読点の表示加工は後段で行う。

1 cue の開始時刻は含まれる最初の語の `start`、終了時刻は最後の語の `end` とする。字幕間の無音は埋めず、segment端まで引き伸ばさない。時刻はSRT / VTTの出力時にミリ秒へ丸める。

1つのWhisperのwordに複数の文が含まれていても、その内部時刻は補間しない。この場合はwordを分割せず扱う。

## 日本語のまとまり

Whisperのwordをそのまま日本語の単語としては扱わない。Python標準ライブラリの規則で原文上の境界候補を制限する。追加の形態素解析辞書は使用しない。

- 「について」「に関して」「に対して」「かもしれない」などの接続表現・連語の内部を保護する。
- 連続するひらがな・カタカナ・漢字・英数字表記の内部を保護する。複合語を無理に細分化しない。
- 次の語が助詞・助動詞・活用語尾と判断される場合、その手前では切らない。
- 句読点、空白、助詞を含む節の末尾、丁寧形などの語尾を候補とする。
- 「はい」「いいえ」「わかりました」など、登録された独立返答は隣接するひらがな列からも区別する。
- 数値内部、閉じ括弧や単独句読点の手前では切らない。

例えばWhisperが「この件につい」「て」「説明します」と返しても、「につい」と「て」の間では切らない。語間に十分な間があれば「この件について」／「説明します」の区切りを候補にできる。

辞書を使った形態素解析ではないため、未知語・口語・ひらがなだけの長い文などの境界を網羅しない。判断できないつながりは分割を控える。保護対象の表現内部に長い時間差がある場合も、その内部に時刻を補間して新しい境界を作ることはしない。

## 境界の選択と短い断片の調整

日本語のまとまりを壊さず、かつWhisperのword間に存在する候補について、次の規則を適用する。

| 手がかり | 動作 |
|---|---|
| 句点・疑問符・感嘆符などの文末 | 短い発話でも区切りを維持する |
| 読点 | 語間の間、または直前の節の発話時間を満たす場合に区切る。読点だけで毎回切らない |
| 通常の語間の間 | 文節・語尾・空白などの候補で区切る |
| 長い語間の無音 | 確定した区切りを短い断片の結合で取り消さない |
| 短い独立返答 | 読点や語間の間による区切りを維持する |
| 短い非独立の断片 | 弱い区切りを取り消して前後と結合する |

「発話時間」は各語の `end - start` の合計とし、語間の無音を除く。極端に短い断片を減らす際も文末・独立返答・長い無音の区切りはまたがない。隣接する正常なsegmentは、文末や無音などの区切りがない場合、連続した原文として扱う。「につい」／「て説明します」のようなsegment境界でも語の途中を避ける。長い無音があるsegment境界と、フォールバックしたsegmentの前後では結合しない。独立返答のsegmentも維持するが、「そう」／「です」のように後続が付属語の場合はひとまとまりにする。

長い無音の判定は音声波形の解析ではなく、`次の語.start - 前の語.end` による。単語時刻そのものの誤差や1語内の無音は、この処理だけでは修正できない。

## 調整可能な閾値

`subtitle.py` 冒頭の `SegmentationConfig` に秒単位で集約する。既定インスタンスは `SEGMENTATION_CONFIG`。CLIの引数は増やさない。比較は出力と同じミリ秒単位に丸め、浮動小数点の誤差で閾値ちょうどの間を見落とさない。

| フィールド | 既定値 | 意味 |
|---|---:|---|
| `pause_seconds` | 0.5 | 句読点がない箇所を含む、通常の区切り候補に必要な語間の間 |
| `comma_pause_seconds` | 0.25 | 読点による区切りに必要な語間の間 |
| `long_pause_seconds` | 1.0 | 短い断片を結合してもまたがない無音、segment結合を停止する無音 |
| `clause_speech_seconds` | 3.0 | 間が短くても読点を区切り候補にする節の発話時間 |
| `min_cue_speech_seconds` | 0.8 | これ未満の非独立の断片を結合候補にする発話時間 |

閾値は文字数や字幕の最大表示時間ではない。短い返答・独立文・長い無音に挟まれた発話は0.8秒未満でも残る。句読点や安全な境界がない長文を、別の固定制限で強制分割することもない。

表現の保護は同じファイル冒頭の `JAPANESE_EXPRESSIONS`、語尾や付属語のパターン、`INDEPENDENT_RESPONSES` で調整できる。表現を追加・変更する場合は語途中分割と本文保存の回帰テストを追加する。

## フォールバックとエラー

以下のいずれかを検出したsegmentは分割しない。そのsegmentの原文全体と元の `start` / `end` を使い、stdoutへsegmentの番号・時刻範囲・理由を出す。

- `words` がない、`None`、空。
- 語の開始・終了時刻が欠損、非数値、NaN、無限大、負値、逆転、ゼロ長、またはミリ秒へ丸めるとゼロ長。
- 語時刻が元segment範囲の外に出ている。
- 語の順序が逆転、または前の語の終了より先に次の語が始まって重なっている。
- 語の本文が欠損・空、原文と一致しない、原文全体を覆わない。

例:

```text
Subtitle fallback: segment 2 [4.000, 8.000]: missing word timestamps
```

欠けた単語や文字を推測して修復しない。正常な隣のsegmentの本文・時刻はそのまま処理する。フォールバックにも最後の表示用加工は適用するが、認識された本文の語を落とさない。

元segment時刻自体が不正、または隣接segmentと重複する場合は有効なフォールバック時刻がないためエラーにする。SRT / VTTは全cueの生成を終えてからファイルを開くため、この検証エラーで既存出力ファイルを上書きしない。

## 表示と形式

`create_subtitle_cues()` は句読点・空白を保持した原文のcueを返す。SRT / VTT writerだけが `normalize_subtitle_text()` を適用する。

- 文末や読点として判定した句読点を除去する。
- 小数点、桁区切り、時刻や比率のコロンは保持する。例: `1.5万円`、`.5`、`1,000円`、`10:30`、`１．５万円`。
- 英数字の内部のピリオドなど、表記に使われる記号を保持する。コロン・セミコロン・演算子・引用符・括弧などは一律削除しない。
- 表示のため改行・連続空白を単一スペースに整理する。句読点や空白だけのcueは出力しない。
- SRT: 1からの連番、`HH:MM:SS,mmm`、本文、空行。
- VTT: `WEBVTT` ヘッダー、`HH:MM:SS.mmm`、本文、空行。
- TXT: `segment.text` をそのまま書き、末尾に改行を追加する。分割も表示用句読点除去も適用しない。

## 依存関係・同梱

Python標準ライブラリのみで境界・時刻・表示処理を実装する。新しいインストール手順、辞書ダウンロード、PyInstallerのhidden import・データ収集設定は不要。既存の `scripts/subtitle_cli_entry.py` と `npm run build:app` を使う。

`word_timestamps=True` の追加に伴う実際の認識時間・メモリへの影響は音声と環境に依存し、今回の合成データのテストでは測定しない。

## 検証と残る制約

`tests/test_subtitle.py` で、固定文字数分割の撤廃、句読点・間・表現保護、短い返答、非均一な語時刻、数値表記、原文の欠落・重複、各種フォールバック、SRT / VTTの共通性、TXTの原文保持、CLI引数と呼び出しを検証する。長時間相当の合成segment列についても本文保存と時刻順序を検証する。

この検証は認識結果・時刻の合成データとCLIのモックによるもの。実音声の認識精度、発話と字幕の同期精度、長時間音声の実測処理速度を実証したものではない。

今後の実音声検証では、長い講演・短い応答を含む対話・句読点が少ない発話について、長すぎる字幕、誤った境界、語時刻のずれ、フォールバック頻度を確認する必要がある。規則による日本語判定とWhisperの単語時刻には限界があり、すべての発話を文法的に解析したり同期誤差を補正したりすることはできない。
